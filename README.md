# Property Path Calculator

An Estate Basics calculator for three property journeys:

- Buying a first HDB
- Buying a first condo
- Selling an HDB and buying a condo

Visitors can use the calculator without sharing their details. The optional sense-check form records their chosen path and estimate before opening WhatsApp.

## Publishing

GitHub Actions publishes `dist/client` to GitHub Pages whenever `main` is updated. In the repository settings, set **Pages → Source** to **GitHub Actions**. A custom domain can then be added under **Pages → Custom domain**.
